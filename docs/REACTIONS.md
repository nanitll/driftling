# Характер и реакции (фаза G5)

Карта того, как питомец отвечает на действия человека и на мир вокруг.
Цель — чтобы взаимодействие было **процессом с сюрпризами**, а не набором
кнопок: каждое естественное движение мышью что-то значит, а редкие вещи
находятся сами и радуют.

Принципы:

- **Никаких попапов**: всё выражается позой, анимацией, коротким пузырём.
- **Физика честная** (см. `core::body`): реакции вырастают из неё, а не
  накладываются сверху — укачивает от реальной тряски, шишка — от реального
  удара.
- **Последствия настоящие**: то, что сделано с питомцем, попадает в журнал
  и влияет на статы (`Shaken`, `Fed`, `Played`…), а значит и синкается.
- **Редкое остаётся редким**: пасхалки срабатывают не чаще, чем нужно, чтобы
  их можно было заметить и удивиться, но не устать.

## Мышь и руки

| Действие | Реакция | Статус |
|---|---|---|
| Клик | поглаживание: радостная морда 1.2 с, `Petted` | есть |
| Любое движение и удар | тело мягкое: сминается о пол, вытягивается в полёте, дышит в покое, хохолок заваливается по инерции (G6) | есть |
| **Зажать и держать** (не двигая, > 1.2 с) | мурлыканье: над головой всплывают сердечки, каждые ~0.8 с ещё одно, пока держишь; настроение +, но с почасовым потолком (анти-фарм из B5) | G5 |
| **Двойной клик** | радостный прыжок на месте (0.35 м) | G5 |
| **Частые клики** (5 за 2 с) | раздражение: «!» и отворачивается | G5 |
| **Совсем достали** (8+ за 3 с) | обиделся: убегает за край экрана на 15 с, возвращается сам | G5 |
| Перетаскивание | висит в руке; на стене/потолке снимается «на ноги» | есть |
| Отпустить | бросок по скорости руки с мягким насыщением к пределу тела | есть |
| Потерян захват (курсор ушёл при зажатой кнопке) | НЕ бросок: выпадает из руки на месте | есть |
| **Тряска** (развороты руки на скорости > 2 м/с) | укачивает не сразу: ~3 с бодрой тряски — позеленел и шатается, ~6.5 с — стошнит. Обычный перенос, в том числе по диагонали, не укачивает вовсе. Тошнота не теряется, если после тряски питомца бросили: отыграется, когда встанет на землю. Лужица ~25 с, `Shaken` (настроение −12, здоровье −3) | есть |
| Сильный бросок | «Уиии!» в полёте; кувыркается; тело вытянуто в полёте и сминается о пол, из-под ног летит пыль | есть |
| Бросок в потолок | цепляется и висит обезьянкой; слишком сильно — шишка со звёздочками | есть |
| Бросок в стену | цепляется и лезет в профиль | есть |

## Уход (меню ПКМ)

| Действие | Реакция | Статус |
|---|---|---|
| Покормить | ест печенье 2.5 с | есть |
| Вкусняшка | то же, настроение выше, здоровье страдает при злоупотреблении | есть |
| **Перекорм** (3 вкусняшки за минуту) | икота: «Ик!» каждые несколько секунд полминуты | G5 |
| Поиграть | радость 2 с | есть |
| Уложить спать | засыпает (со стены — сперва спускается); уставший спит дольше | есть |
| Перекрасить | коротко радуется новому цвету | G5 |
| Убрать с экрана | машет лапкой «Пока!» 0.9 с и только потом уходит за край | есть |

## Бэклог сюрпризов (следующие волны)

- Взгляд за курсором, когда он рядом (нужен глобальный указатель — на
  Wayland его нет; на X11 можно).
- Ночью (22:00–06:00) спит в колпаке; утром потягивается особенно долго.
- Ловля мухи: резкие короткие пробежки за невидимой точкой.
- Первый снег/погода по системному календарю — сезонные шапки.
- Реакция на имя: если назвать `Кот` — иногда мяукает пузырём.
- Игра в мяч: мячик-предмет, который можно кинуть питомцу, он приносит.
- Совместные реакции двух устройств: «скучал» по возвращении с другого ПК.
