# Driftling

Опенсорс десктопный тамагочи: питомец живёт на экране, ходит по кромкам и окнам, требует ухода и растёт. Один и тот же питомец на всех ваших устройствах — через свой сервер (VPS/домашний ПК) или общий хост; он «перебегает» на то устройство, за которым вы сидите. Linux (Wayland-first) → Windows → macOS → Android/веб.

Статус: **предрелиз** — питомец ходит по окнам (KDE Wayland проверено вживую; sway/Hyprland/X11 — код есть), лазает по стенам и висит под потолком, полный тамагочи-цикл с ростом, физика тела в реальных единицах, реакции и пасхалки, радиальное меню, синк через свой сервер или папку с хэндоффом между устройствами. Осталась дистрибуция (deb/AppImage/AUR) и полировка до 1.0 — см. дорожную карту.
