# Driftling

Опенсорс десктопный тамагочи: питомец живёт на экране, ходит по кромкам и окнам, требует ухода и растёт. Один и тот же питомец на всех ваших устройствах — через свой сервер (VPS/домашний ПК) или общий хост; он «перебегает» на то устройство, за которым вы сидите. Linux (Wayland-first) → Windows → macOS → Android/веб.

Статус: **ранний прототип** — питомец ходит по экрану (M0), есть окно настроек (M0.5); тамагочи-механики и окна-рельеф в работе.
